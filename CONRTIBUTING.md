# Contributing to TorchQuery

Welcome to the TorchQuery community! We are thrilled that you're interested in improving this project. To ensure a smooth experience for everyone, please follow these guidelines.

## 1. How to Contribute
- **Bug Reports:** Open an issue with a clear description and steps to reproduce.
- **Features:** Before starting a large feature, open an issue to discuss it with the maintainers.
- **Code Changes:** Please follow the coding style (run `black` and `ruff` before pushing).

## 2. Pull Request Guidelines
- **Labels:** You MUST add the appropriate label (e.g., `cc: feat`, `cc: fix`, `cc: docs`).
- **Titles:** Use the format `type(scope): description` (e.g., `feat(query): add semantic search`).
- **Testing:** Add tests for your changes. We value high test coverage.
- **Documentation:** If you add a new function, include a docstring.

## 3. Local Setup
1. Fork and clone the repo.
2. Install requirements: `pip install -r requirements.txt`.
3. Set up the pre-commit hooks to ensure code quality: `pre-commit install`.

## 4. Good First Issues
New to the project? Look for issues labeled with `good-first-issue`. These are mentored tasks designed to help you get familiar with the codebase.

## 5. Code of Conduct
Please be respectful and supportive in all discussions. We are here to learn and build great things together.
